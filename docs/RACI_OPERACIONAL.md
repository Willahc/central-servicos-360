## 1. Legenda do Modelo RACI

- **R (Responsible / Responsável Executor)**: Quem realiza a atividade operacional.
- **A (Accountable / Aprovador / Dono)**: Quem possui a palavra final e presta contas pelo resultado.
- **C (Consulted / Consultado)**: Quem fornece insumos e parecer técnico.
- **I (Informed / Informado)**: Quem é notificado sobre o andamento e conclusão.
